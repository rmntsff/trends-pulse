# Trends Pulse — Telegram Mini App

Топ трендів Google для України, США та ще однієї країни на вибір, з коротким поясненням від Gemini (✨)
або заголовком новини (📰). Працює всередині Telegram на Android, iPhone, комп'ютері й у веб-версії.

Складається з двох частин, які розгортаються разом на Cloudflare Workers (безкоштовно):

- `public/` — сама сторінка Mini App (HTML, CSS, JavaScript без збірки);
- `src/` — сервер: забирає RSS Google Trends, звертається до Gemini, кешує відповіді й перевіряє,
  що запит справді прийшов від дозволеного користувача Telegram.

Ключ Gemini і токен бота зберігаються лише на сервері як секрети. У сторінку вони не потрапляють.

## Розгортання (один раз, близько 15 хвилин)

### 1. Підготовка

1. Встановіть [Node.js](https://nodejs.org) (версія LTS).
2. Зареєструйтеся на [cloudflare.com](https://dash.cloudflare.com/sign-up) (картка не потрібна).
3. Відкрийте термінал у папці проєкту і встановіть залежності:

```bash
npm install
```

### 2. Створіть бота

1. У Telegram відкрийте [@BotFather](https://t.me/BotFather) і надішліть `/newbot`.
2. Задайте назву (наприклад, `Trends Pulse`) та ім'я користувача (має закінчуватися на `bot`).
3. BotFather надішле **токен** виду `1234567890:AA…`. Це секрет: нікому його не показуйте.

### 3. Розгорніть сервер

Увійдіть у Cloudflare (відкриється браузер):

```bash
npx wrangler login
```

Розгорніть застосунок:

```bash
npm run deploy
```

Наприкінці команда надрукує адресу виду `https://trends-pulse.ВАШЕ-ІМ'Я.workers.dev`. Збережіть її.

Тепер задайте два секрети. Кожна команда попросить вставити значення (його не буде видно на екрані):

```bash
npx wrangler secret put BOT_TOKEN
```

```bash
npx wrangler secret put GEMINI_API_KEY
```

Ключ Gemini береться на <https://aistudio.google.com/app/apikey>.

### 4. Підключіть Mini App до бота

1. У @BotFather надішліть `/mybots` → виберіть бота → **Bot Settings** → **Menu Button** → **Configure menu button**.
2. Надішліть адресу з кроку 3, потім назву кнопки (наприклад, `Тренди`).

### 5. Дайте собі доступ

1. Відкрийте свого бота в Telegram і натисніть кнопку меню **Тренди**.
2. Застосунок покаже «Немає доступу» і ваш номер (Telegram ID). Скопіюйте його.
3. У файлі `wrangler.jsonc` впишіть номер у рядок `ALLOWED_USER_IDS`, наприклад:
   `"ALLOWED_USER_IDS": "123456789"`
4. Розгорніть ще раз:

```bash
npm run deploy
```

Відкрийте бота знову: тренди мають завантажитися.

## Як додати знайомих

Людина відкриває бота, бачить свій номер і надсилає його вам. Ви дописуєте номер у `ALLOWED_USER_IDS`
через кому (`"123456789,987654321"`) і виконуєте `npm run deploy`.

## Налаштування

| Що | Де | Як змінити |
|---|---|---|
| Хто має доступ | `ALLOWED_USER_IDS` у `wrangler.jsonc` | відредагувати й `npm run deploy` |
| Модель Gemini | `GEMINI_MODEL` у `wrangler.jsonc` | так само |
| Ключ Gemini | секрет `GEMINI_API_KEY` | `npx wrangler secret put GEMINI_API_KEY` |
| Токен бота | секрет `BOT_TOKEN` | `npx wrangler secret put BOT_TOKEN` |

Якщо основна модель перевантажена, без квоти або зникла, сервер сам пробує резервні
(`gemini-3.6-flash`, потім `gemini-3.5-flash-lite`). Яка модель відповіла, видно на картці.

Якщо пояснень немає, натисніть ✨ у застосунку: там показано останню відповідь Google.
Журнал сервера в реальному часі:

```bash
npx wrangler tail
```

## Локальний запуск і тести

```bash
npm test
```

Для запуску на своєму комп'ютері скопіюйте `.dev.vars.example` у `.dev.vars`, впишіть ключ Gemini й виконайте:

```bash
npm run dev
```

`DEV_BYPASS_AUTH=1` у `.dev.vars` вимикає перевірку Telegram, щоб сторінку можна було відкрити
у звичайному браузері. Ніколи не задавайте цю змінну на сервері.

## Безпека

- Кожен запит до `/api/*` несе підписані Telegram дані (`initData`). Сервер перевіряє підпис
  токеном бота, тож підробити чужий акаунт не можна. Дані старші за добу відхиляються.
- Сервер пояснює лише тренди зі своєї копії RSS. Клієнт передає тільки країну й ключі трендів,
  тому ендпоінт не можна використати як безкоштовний доступ до Gemini з довільним текстом.
- Посилання з RSS відкриваються, лише якщо це `http`/`https`. Увесь текст вставляється в сторінку
  як текст, а не як HTML. Content-Security-Policy дозволяє скрипти лише з власної адреси та `telegram.org`.
- Не додавайте в git файли `.dev.vars` та `.env` (вони вже в `.gitignore`).

## Обмеження

- RSS Google Trends — неофіційне джерело: формат або доступність можуть змінитися. У ньому лише
  поточні тренди країни (приблизно за добу), без періодів, категорій і демографії.
- Кеш (тренди на 5 хвилин, пояснення на 6 годин) живе в пам'яті сервера. Cloudflare періодично
  перезапускає екземпляри, і тоді перший запит знову йде до Google та Gemini. Для кількох
  користувачів цього досить; для відкритого бота варто підключити Cloudflare KV.

## Платний доступ на майбутнє

Рішення «чи має користувач доступ» ухвалюється в одній функції: `hasAccess` у `src/auth.ts`.
Щоб продавати доступ, потрібно:

1. сховище підписок (Cloudflare KV або D1): `ID користувача → оплачено до`;
2. оплата через Telegram Stars: бот надсилає рахунок (`sendInvoice` з валютою `XTR`), а сервер
   приймає від Telegram повідомлення про успішну оплату (webhook) і записує підписку;
3. `hasAccess` перевіряє список `ALLOWED_USER_IDS` або активну підписку;
4. обмеження кількості запитів на користувача, щоб ніхто не вичерпав вашу квоту Gemini.

Для цифрових послуг усередині Telegram правила платформи вимагають саме Telegram Stars.
